OVERVIEW

Flowsint is a modular Open Source Intelligence (OSINT) investigation and reconnaissance platform designed to collect, enrich, correlate, and visualize publicly available information.

It provides graph-based visualization for exploring relationships between entities and supports multiple intelligence sources through extensible enrichers and automated investigation workflows. Flowsint focuses on modularity, local execution, privacy, and extensibility.


KEY FEATURES

- Graph-Based Visualization: Explore complex relationships between entities intuitively.
- Automated Enrichment: Gain insights through supported OSINT enrichers.
- Investigation Flows: Connect multiple enrichment steps into seamless workflows.
- Modular Architecture: Build custom tools and enrichers easily.
- Local Data Control: Retain full privacy and ownership over investigation data.
- Vault System: Safely manage sensitive configuration values and credentials.
- Extensible Workflows: Adapt as OSINT sources and reconnaissance tools evolve.


OBJECTIVES

- Centralize OSINT information from multiple sources.
- Discover and analyze relationships between entities.
- Reduce repetitive manual investigation tasks.
- Automate supported reconnaissance and enrichment workflows.
- Support cybersecurity research and threat intelligence.
- Provide a flexible foundation for custom OSINT integrations.


INSTALLATION

Prerequisites
Install the required dependencies as described in the official quickstart guide:
https://www.flowsint.io/docs/getting-started/quickstart

Common tools include:
- Git
- Docker and Docker Compose
- Make

Ubuntu / Kali Linux

Step 1. Clone the official repository:

git clone https://github.com/reconurge/flowsint.git
cd flowsint

Step 2. Start the project using the build command:

make prod

Step 3. Open the local address shown in the terminal output to access the dashboard.

Official Guide: https://www.flowsint.io/docs/getting-started/quickstart


BASIC USAGE

1. Start Flowsint and open its web interface.
2. Create a new investigation or open an existing one.
3. Add a supported entity (for example, a domain name).
4. Choose an appropriate enricher.
5. Review the returned information and discovered entity relationships.
6. Expand the graph to investigate related entities.
7. Combine supported enrichment steps into automated flows when appropriate.
