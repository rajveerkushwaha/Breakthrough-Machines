# Nmap — Network Discovery and Security Auditing

Official Website: https://nmap.org/
Official Documentation: https://nmap.org/book/man.html
Official Repository: https://github.com/nmap/nmap

## Overview

Nmap (Network Mapper) is an open-source network discovery and security auditing tool used to identify active hosts, discover open ports, detect services and their versions, and perform network reconnaissance.

It is widely used by cybersecurity professionals, network administrators, penetration testers, and security researchers to assess network exposure and understand services running on authorized systems.

## Key Features

- Host discovery to identify active systems.
- Port scanning to determine accessible TCP and UDP ports.
- Service detection to identify services running on discovered ports.
- Version detection to estimate service and application versions.
- Operating-system detection.
- Nmap Scripting Engine (NSE) for extending scanning capabilities.
- Network inventory and security auditing.
- Output in normal text, XML, and grepable formats.

## Objectives

- Understand network topology and host availability.
- Identify exposed ports and services.
- Support authorized vulnerability assessments.
- Assist with network troubleshooting and security auditing.
- Develop practical network reconnaissance skills.

## Installation

### Kali Linux

Check whether Nmap is installed:

    nmap --version

Install it if needed:

    sudo apt update
    sudo apt install nmap -y

### Ubuntu Linux

    sudo apt update
    sudo apt install nmap -y

Verify the installation:

    nmap --version

## Basic Usage

Replace TARGET_IP with the IP address or hostname of a system you are authorized to scan.

### 1. Scan a target

    nmap TARGET_IP

Scans commonly scanned TCP ports on the target.

### 2. Scan specific ports

    nmap -p 22,80,443 TARGET_IP

Scans TCP ports 22, 80, and 443.

### 3. Scan all TCP ports

    nmap -p- TARGET_IP

Scans all 65,535 TCP ports.

### 4. Detect service versions

    nmap -sV TARGET_IP

Attempts to identify services and their versions.

### 5. Detect the operating system

    sudo nmap -O TARGET_IP

Attempts operating-system detection. Accuracy depends on network responses and scanning conditions.

### 6. Perform a TCP SYN scan

    sudo nmap -sS TARGET_IP

Performs a TCP SYN scan, generally requiring elevated privileges for raw packet access.

### 7. Discover hosts on a local network

    nmap -sn 192.168.1.0/24

Performs host discovery without a port scan. Replace the subnet with your authorized network range.

### 8. Scan selected UDP ports

    sudo nmap -sU -p 53,123,161 TARGET_IP

Scans the specified UDP ports, commonly associated with DNS, NTP, and SNMP.

### 9. Save scan results

Normal text output:

    nmap -oN scan_results.txt TARGET_IP

XML output:

    nmap -oX scan_results.xml TARGET_IP

Save in multiple major output formats:

    nmap -oA scan_results TARGET_IP
