# Flowsint — Graph-Based OSINT Investigation Platform

Website: https://www.flowsint.io/
Documentation: https://www.flowsint.io/docs/overview
Official Repository: https://github.com/reconurge/flowsint

## Overview

Flowsint is a modular Open Source Intelligence (OSINT) investigation and reconnaissance platform designed to collect, enrich, correlate, and visualize publicly available information.

It provides graph-based visualization for exploring relationships between entities and supports multiple intelligence sources through extensible enrichers and automated investigation workflows. Flowsint focuses on modularity, local execution, privacy, and extensibility.

## Key Features

- Graph-based visualization of entity relationships.
- Automated enrichment through supported OSINT enrichers.
- Investigation flows that connect multiple enrichment steps.
- Modular architecture for custom tools and enrichers.
- Local data storage for greater control over investigation data.
- Vault for managing sensitive configuration values and credentials.
- Extensible workflows that can adapt as sources and tools change.

## Objectives

- Centralize OSINT information from multiple sources.
- Discover and analyze relationships between entities.
- Reduce repetitive manual investigation tasks.
- Automate supported reconnaissance and enrichment workflows.
- Support cybersecurity research and threat intelligence.
- Provide a flexible foundation for custom OSINT integrations.

## Installation

### Prerequisites

Install the dependencies required by the current official project documentation. Common tools may include Git, Docker, Docker Compose, and Make.

### Ubuntu / Kali Linux

Clone the official repository:

    git clone https://github.com/reconurge/flowsint.git
    cd flowsint

Use the startup command specified by the current official installation guide. The project documentation has referenced:

    make prod

Open the local address shown in the application output or installation documentation. Confirm the required dependencies, configuration, command, and port for the version you install.

Installation guide: https://www.flowsint.io/docs/getting-started/quickstart

## Basic Usage

1. Start Flowsint and open its web interface.
2. Create or access an investigation.
3. Add a supported entity, such as a domain.
4. Select an appropriate enricher.
5. Review the returned information and discovered relationships.
6. Expand the graph to investigate related entities.
7. Combine supported enrichment steps into automated flows when appropriate.

Available enrichment capabilities depend on the installed version and configured integrations.
