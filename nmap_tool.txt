Website: https://nmap.org/

GitHub: https://github.com/nmap/nmap


OVERVIEW

Nmap (Network Mapper) is a free, open-source utility for network discovery and security auditing. It is designed to rapidly scan large networks, find active hosts, discover open ports, identify running services and their versions, and detect operating system details.

It is widely used by system administrators, cybersecurity professionals, penetration testers, and security researchers for network inventory, managing service upgrade schedules, and monitoring host or service uptime.


KEY FEATURES

- Host Discovery: Identify active systems on a network.
- Port Scanning: Discover open TCP and UDP ports.
- Service and Version Detection: Determine service signatures and version details.
- OS Detection: Estimate host operating systems and hardware characteristics.
- Nmap Scripting Engine (NSE): Extend functionality using Lua scripts for vulnerability detection and advanced reconnaissance.
- Flexible Output Formats: Save scan results in text, XML, or grepable formats.


OBJECTIVES

- Understand network topology and host availability.
- Identify exposed ports and potentially vulnerable services.
- Assist with network troubleshooting and security auditing.
- Support authorized vulnerability assessments.
- Build practical, hands-on skills in network reconnaissance.


INSTALLATION

Kali Linux
Nmap comes pre-installed on Kali Linux. Check your version:

nmap --version

If it is missing or needs an update:

sudo apt update && sudo apt install nmap -y

Ubuntu Linux

sudo apt update
sudo apt install nmap -y

Verify installation:

nmap --version


BASIC USAGE

Note: Replace TARGET_IP with the target IP address or domain name you are explicitly authorized to scan.

1. Basic Target Scan (scans the 1000 most common TCP ports)
nmap TARGET_IP

2. Scan Specific Ports (ports 22, 80, and 443)
nmap -p 22,80,443 TARGET_IP

3. Scan All TCP Ports (all 65535 ports)
nmap -p- TARGET_IP

4. Service Version Detection
nmap -sV TARGET_IP

5. Operating System Detection (requires root or sudo)
sudo nmap -O TARGET_IP

6. TCP SYN Stealth Scan
sudo nmap -sS TARGET_IP

7. Local Subnet Host Discovery (ping sweep, no port scan)
nmap -sn 192.168.1.0/24

8. Scan Selected UDP Ports (DNS, NTP, SNMP)
sudo nmap -sU -p 53,123,161 TARGET_IP

9. Save Output
Normal text:
nmap -oN scan_results.txt TARGET_IP

XML output:
nmap -oX scan_results.xml TARGET_IP

All major formats (text, XML, grepable):
nmap -oA scan_results TARGET_IP
